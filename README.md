# مكتبة بين المتون

موقع من صفحة واحدة يعرض كتب سلسلة «بين متنين» للقراءة والتحميل.
إعداد: كليب بن أحمد بن ضيف الله الزهراني.

## المحتوى
- `index.html`: الموقع كله في ملف واحد (التصميم والبرمجة والأغلفة داخله).
- `books/`: ملفات الكتب الأربعة بصيغة PDF.

- `og-image.jpg`: الصورة التي تظهر عند إرسال الرابط في واتساب وتلجرام والرسائل.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا عامًّا باسم `bayn-al-mutun`.
2. ارفع `index.html` و`og-image.jpg` و`.nojekyll` ومجلد `books` كما هي (Add file ← Upload files).
3. من Settings ← Pages اختر: Deploy from a branch، الفرع `main`، المجلد `/ (root)`، ثم Save.
4. بعد دقيقة أو دقيقتين يظهر الموقع على: https://kmasskmass-svg.github.io/bayn-al-mutun/

ملاحظة: واتساب يحفظ المعاينة مدة، فإن أرسلت الرابط قبل اكتمال النشر وظهر بلا صورة فأضف في آخره `?v=1` وأعد إرساله.
